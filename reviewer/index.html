Setup

How to test

  1. Install the submitted Chrome extension package from the Chrome Web Store review flow.
  2. Download the local companion service package from this page and unzip it.
  3. Open a terminal in the unzipped folder.
  4. Run npm install.
  5. Run npm run dev or node server.js.
  6. Confirm the terminal prints that the service is running. The default service URL is http://localhost:3001.
  7. Open any ordinary webpage in Chrome.
  8. Click the PM原型拾取器 extension icon.
  9. Confirm the popup shows the local service as connected.
  10. Click 一键同步到AI.
  11. Wait until the extension reaches the success state, then click 预览还原页面.
