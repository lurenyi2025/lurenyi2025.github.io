Data Processed

1. 我们处理的数据

当用户主动点击扩展中的“一键同步到AI”按钮时，扩展会处理当前活动网页中与原型还原相关的内容。

  • 当前网页的可见截图。
  • 页面 DOM 结构、文本内容、样式信息和布局信息。
  • 图片、字体、CSS 等资源引用，以及生成原型工程所需的资源线索。
  • 当前页面标题、URL、扩展同步阶段、进度信息、错误状态和本地预览地址。
Not Collected

2. 我们不收集的数据

PM原型拾取器的设计目标是页面原型还原，不是用户跟踪、广告投放或身份识别。

  • 不主动收集姓名、邮箱、电话号码、身份证件号码等个人身份信息。
  • 不收集健康信息、财务和付款信息、身份验证信息或个人通讯内容。
  • 不收集用户浏览历史列表、点击记录、鼠标轨迹、滚屏记录或跨站行为数据。
  • 不收集 GPS 坐标或用户设备附近事物的位置信息。
Purpose

3. 数据用途

扩展处理网站内容的单一用途是：将用户当前选择的网页转换为可预览、可继续由 AI 编辑的本地原型工程。

页面还原 抓取页面结构、视觉证据和资源信息，用于生成本地原型。
同步进度展示 在扩展弹窗中显示本地服务连接、同步阶段和预览地址。
AI 编辑上下文 为用户后续的 AI 原型编辑提供必要的页面上下文。
本地预览 同步完成后打开用户本机生成的预览页面。
Localhost

4. 数据传输与存储

扩展会把用户主动触发抓取后的页面数据发送到用户本机运行的 localhost 配套服务处理。该服务用于在用户本机生成原型工程和预览页面。

  • 扩展不会把页面抓取数据上传到第三方云端服务器。
  • 扩展使用 Chrome 本地存储保存运行状态，例如服务端口、当前阶段、进度信息和预览地址。
  • 这些运行状态保存在用户本机浏览器中，可通过浏览器设置或移除扩展清除。
Sharing

5. 数据共享

我们不会出售用户数据，不会将用户数据用于广告，也不会把用户数据转交第三方用于与扩展核心功能无关的用途。

  • 不会出于已获批准用途之外的用途向第三方出售或传输用户数据。
  • 不会为实现与产品单一用途无关的目的而使用或转移用户数据。
  • 不会为确定信用度或实现贷款而使用或转移用户数据。
Remote Code

6. 远程代码

PM原型拾取器 Chrome 扩展不加载或执行远程托管代码。所有扩展脚本均包含在提交到 Chrome Web Store 的扩展安装包中。

扩展可能打开官方网站或服务说明页面，用于查看产品说明或获取配套本地服务，但不会从该网站加载或执行远程代码来改变扩展行为。

User Control

7. 用户控制

用户可以通过以下方式控制扩展的数据处理：

  • 仅在需要时点击扩展并主动发起同步。
  • 停止或关闭本机配套服务，阻止扩展继续连接 localhost 服务。
  • 在 Chrome 中停用或移除扩展。
  • 清除浏览器扩展本地存储，删除保存的运行状态。
Limited Use

8. Limited Use 声明

PM原型拾取器对用户数据的使用符合 Chrome Web Store User Data Policy，包括 Limited Use 要求。

  • 用户数据仅用于提供或改进扩展的单一核心功能。
  • 不会将用户数据用于广告、营销画像或与原型还原无关的分析。
  • 不会出售用户数据，也不会将用户数据转交第三方用于无关目的。
重点提示：PM原型拾取器是面向 PM 的网页原型辅助工具，只处理用户主动选择的当前页面内容，并将抓取结果发送到用户本机服务进行处理。
